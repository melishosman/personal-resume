# Personal Resume

A multi-page, pure HTML personal resume website created to showcase my background, technical skills, education, and certifications.

## 📌 Features
- Built entirely with semantic **pure HTML5**
- Multi-page navigation (Resume, About Me, Contact Me)
- Organized structure covering Experience, Skills, Certifications, and Languages

## 🛠️ Built With
- **HTML5** (Semantic Elements & Unicode character entities)
